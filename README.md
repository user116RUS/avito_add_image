# Обработка объявлений Avito с уникализацией изображений

## Описание
Этот скрипт автоматизирует процесс обработки XML-файла с объявлениями, создание модифицированных изображений и генерацию Excel-таблицы для последующей загрузки на Авито.

Основные возможности:
- Загрузка XML-файла с объявлениями
- Обработка изображений с использованием Python-библиотек (Pillow, OpenCV):
  - Изменение контраста и резкости
  - Добавление зернистости (шума)
  - Корректировка яркости и цветового баланса
  - Имитация фотографий с разных устройств
- Создание дубликатов объявлений для разных городов
- Загрузка модифицированных изображений на Google Drive
- Генерация Excel-файла для импорта на Avito

## Требования
- Python 3.8+
- Необходимые библиотеки:
  - pandas, openpyxl: для работы с Excel
  - Pillow, opencv-python, numpy: для обработки изображений
  - requests: для загрузки данных
  - google-api-python-client: для работы с Google Drive
  - schedule: для периодического запуска задач

## Установка
1. Клонируйте репозиторий
2. Установите зависимости:
```
pip install pandas openpyxl Pillow opencv-python numpy requests google-api-python-client schedule
```
3. Подготовьте файл учетных данных Google Drive (JSON-файл)
4. Создайте следующие папки:
   - `temp` - для временных файлов
   - `fonts` - для шрифтов (опционально)
   - `shop` - для изображений магазина

## Настройка
Настройки по умолчанию хранятся в коде, но вы можете создать файл `config.py` для переопределения любых параметров:

```python
# Пример config.py
XML_URL = "https://example.com/feed.xml"
LOCAL_XML_PATH = "local_xml_copy.xml"
OUTPUT_EXCEL_PATH = "output.xlsx"
GOOGLE_CRED_PATH = "your-credentials.json"
MAX_ITEMS = 10 # Ограничение количества обрабатываемых объявлений
IMAGES_FOLDER_NAME = "my_images"  # Название папки для изображений на Google Drive
MAX_IMAGES_PER_AD = 10  # Максимальное количество изображений для объявления

# Список городов для дублирования
CITIES = [
    "Москва", "Санкт-Петербург", "Новосибирск"
]
```

## Использование
### Одиночный запуск
```
python main_test.py
```

### Периодический запуск
Раскомментируйте соответствующий код в конце файла `main_test.py`:
```python
if __name__ == "__main__":
    main()
    
    # Периодический запуск каждый день в 2 часа ночи
    schedule.every().day.at("02:00").do(main)
    while True:
        schedule.run_pending()
        time.sleep(60)
```

## Структура проекта
- `main_test.py` - основной скрипт
- `config.py` - файл конфигурации (опционально)
- `google_cred.json` - учетные данные Google Drive API
- `fonts/` - директория с шрифтами (опционально)
- `shop/` - директория с изображениями магазина
- `temp/` - директория для временных файлов

## Логирование
Скрипт создает лог-файл `avito_script.log` в текущей директории с подробной информацией о выполнении.

## Примечания
- Для работы с Google Drive необходимо создать сервисный аккаунт и скачать ключ в формате JSON
- Скрипт использует блокировку файлов для предотвращения параллельного запуска нескольких экземпляров
- Для каждого изображения применяется комбинация эффектов (изменение контраста, яркости, добавление шума), чтобы сделать его уникальным
- Если в объявлении менее 10 изображений, добавляются изображения магазина из директории `shop/`
