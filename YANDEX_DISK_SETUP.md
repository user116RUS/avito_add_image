# Настройка Яндекс.Диска

## Получение токена OAuth

1. Перейдите на https://yandex.ru/dev/disk/rest/
2. Нажмите "Получить OAuth-токен"
3. Авторизуйтесь в Яндекс.Паспорте
4. Разрешите доступ к Яндекс.Диску
5. Скопируйте полученный токен

## Настройка переменных окружения

Добавьте в ваш файл `.env`:

```
YANDEX_DISK_TOKEN=ваш_токен_здесь
YANDEX_DISK_FOLDER_PATH=/avito_excel/
```

## Структура папок на Яндекс.Диске

Создайте папку `avito_excel` в корне вашего Яндекс.Диска. В эту папку будут сохраняться Excel-файлы.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Проверка работы

Запустите скрипт для проверки:

```bash
python manage.py update_rows
```

Или используйте daemon.py:

```bash
python daemon.py
```
